# Stage 2.2.2 — Core Toolchain Installation

Install and verify the foundational development toolchain required to begin building the JavaScript Notebook from scratch.

This stage establishes the initial root-level development environment for the full-stack project.

The repository contains three primary implementation areas:

* `frontend/` — client-side application
* `backend/` — server-side application
* `shared/` — code and contracts shared between frontend and backend

The toolchain is intentionally installed at the repository root so that the project remains a single coordinated full-stack repository.

# 2.2.2.10 — Architectural Decision

## Root-Level Toolchain

The project uses a root-level `package.json`.

The root package manifest coordinates the repository rather than creating unrelated package-management roots for the frontend and backend.

### Intended Structure

```text
JavaScript Notepad/
│
├── frontend/
├── backend/
├── shared/
│
├── docs/
│
├── package.json
├── package-lock.json
├── README.md
├── CHANGELOG.md
├── LICENSE
├── .gitignore
├── .gitattributes
└── .env.example
```

### Architectural Principle

The project remains a single Git repository.

The frontend, backend, and shared code are separate architectural areas within that repository.

No nested Git repository should be introduced.
