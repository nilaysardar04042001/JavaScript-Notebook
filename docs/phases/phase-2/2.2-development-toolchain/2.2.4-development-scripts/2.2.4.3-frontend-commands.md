# Stage 2.2.4.3 — Frontend Commands

## Status

**Overall:** Completed

## Parent Stage

**2.2.4 — Development Scripts & Project Commands**

## Objective

Establish and verify the root-level npm commands required to operate the JavaScript Notebook frontend development environment.

This stage connects the root project command interface to the React + Vite frontend configuration established in **2.2.5 — React + Vite Configuration**.

The objective is to provide truthful, directly usable commands for:

- Starting the frontend development server.
- Building the frontend for production.
- Verifying that the configured Vite frontend can start successfully.
- Verifying that the configured Vite frontend can produce a production build.

This stage does not introduce backend runtime commands or complete notebook functionality.

# 2.2.4.3.2 — Command Responsibility

The root `package.json` exposes frontend commands so developers do not need to manually provide the Vite configuration path.

The commands are:

```text
dev:frontend
build:frontend
```

These commands operate specifically against:

```text
frontend/vite.config.ts
```

---

# 2.2.4.3.3 — Development Command

The frontend development command is:

```text
npm run dev:frontend
```

The configured command is:

```json
"dev:frontend": "vite --config frontend/vite.config.ts"
```

Its responsibility is to start the Vite development server using the project's frontend Vite configuration.

Conceptually:

```text
npm run dev:frontend
        │
        ▼
Vite
        │
        ▼
frontend/vite.config.ts
        │
        ▼
Frontend development server
```

# 2.2.4.3.5 — Production Build Command

The frontend production build command is:

```text
npm run build:frontend
```

The configured command is:

```json
"build:frontend": "vite build --config frontend/vite.config.ts"
```

Its responsibility is to execute the Vite production build using the frontend Vite configuration.

Conceptually:

```text
npm run build:frontend
        │
        ▼
Vite build
        │
        ▼
frontend/vite.config.ts
        │
        ▼
Production assets
```

# 2.2.4.3.9 — Relationship With TypeScript Commands

The frontend command set is separate from TypeScript validation.

Frontend development:

```text
npm run dev:frontend
```

Frontend production build:

```text
npm run build:frontend
```

Frontend TypeScript validation:

```text
npm run typecheck:frontend
```

The distinction is intentional:

```text
Frontend Operations
│
├── dev:frontend
├── build:frontend
└── typecheck:frontend
```

Each command has a separate responsibility.

---

# 2.2.4.3.10 — Backend Scope

This stage does not introduce:

```text
dev:backend
build:backend
```

Backend commands remain deferred until the backend runtime and application configuration have been established.

The current backend directory contains the TypeScript configuration foundation but does not yet represent the completed backend runtime.

Therefore no backend runtime command is introduced prematurely.

---

# 2.2.4.3.11 — Full-Stack Development Command

A combined:

