# Stage 2.2.4.3 — Frontend Commands

## Status

**Implementation Complete / Checkpoint Pending**

## Objective

Expose the verified React and Vite frontend workflows through the root `package.json` command interface.

The frontend configuration was established and verified in Stage 2.2.5. This stage adds only commands that invoke that existing configuration.

---

## Commands Introduced

### Development Server

```text
dev:frontend
```

Implementation:

```text
vite --config frontend/vite.config.ts
```

The Vite configuration sets `frontend/` as its root, so this command starts the frontend development server without adding backend behavior.

### Production Build

```text
build:frontend
```

Implementation:

```text
vite build --config frontend/vite.config.ts
```

The build output remains under `frontend/dist/`, which is not tracked by Git.

---

## Command Boundaries

The root `package.json` exposes the commands, while `frontend/vite.config.ts` remains responsible for frontend build configuration.

This stage does not introduce:

- A root `dev` command
- A root `build` command
- Backend commands
- Full-stack process orchestration
- Notebook features

Those capabilities require later, independently verified stages.

---

## Verification Requirements

After implementation, verify:

```text
npm run build:frontend
npm run dev:frontend
git diff --check
git status
```

The production build must complete successfully. The development server must start without configuration errors and then be stopped cleanly.
