# 3. Validation Principle

Validation must prove the existing architecture rather than introduce workarounds.

The validation model is:

```text
Shared source
    │
    ├── shared typecheck
    │
    └── shared production build
             │
             ▼
       shared/dist
             │
             ▼
        backend build
             │
             ▼
      backend runtime
```

At the same time:

```text
frontend
    │
    ├── frontend typecheck
    └── frontend production build
```

The root typecheck must validate the complete TypeScript project relationship.
